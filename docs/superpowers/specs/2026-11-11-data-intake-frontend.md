# 数据接入前端：已确认的小模块修改

用户2026-11-11先纠正FDE工作方式，再确认数据接入首页/单源工作区/接入向导逻辑并要求“请你修改”。只实施该模块，其他前后端业务不改，不再重复询问设计或执行方式。

## 已确认交互

首页围绕数据源列表而非连接器大屏，顶部项目/搜索/新增，显示实际范围/版本/状态/问题。二级同源三栏：左数据集/文件范围，中预览/结构/质量/版本，右字段/片段及来源证据检查器。点击数据集/字段/质量问题联动；接入向导先选方式再选择范围与确认，再实际执行。“配置已保存”不等于数据已接入；结果须可追溯到来源版本。文件真实解析后交接到映射上下文，而不实现本体映射。

## 此次真实范围及已知后端缺口

独立React+TypeScript数据接入模块，在现有预览的sources入口挂载链接，仅替换该入口内容；其他页面设计不迁移、不改功能。包含身份/项目选择的必要最小入口，实际POST二进制文件及Semantica parse队列，真实结果样本/结构/质量（只对已经返回的数据做确定性展示检查，不新建语义解析器），来源版本/SHA/run证据、状态与重试。后端来源支持csv/json/pdf/docx作为parse；CSV只支持UTF8逗号和表头，JSON不接受自定义记录路径，不能显示这些解析配置已可保存。其他格式/数据库/API/知识库有明确限制，连接列表只能读取CONFIGURED记录，无真实DB读取API不能执行接入。

没有服务端源名称/备注/逻辑数据源分组/前后版本关联/字段选择保存/目标目录/映射API。文件本地名称只当前内存显示且标注，刷新显示格式+真实ID；不以localStorage伪装持久化。已有来源Snapshot不可变；更新上传生成独立Snapshot，旧源仍保留，UI不伪造逻辑版本历史或保存业务备注。字段选择只影响预览/映射交接清单，不改变已上传范围，不冒称行列安全策略。

## 安全与状态

Cookie credentials include、同源固定代理保留Origin；生产Secure，明确loopback开发可insecure-dev。不打印/本地保存密码Token/来源正文；401清空当前数据，403显示无权限不是空数据。项目切换和注销的旧响应不回填；原始文件（包括JSON）上传1MiB且非空，API JSON请求体128KiB，固定错误code/run_id。文件名称只显示文本不innerHTML。渲染有限真实样本，未知类型/缺失置信度不编造。

Job关联：成功Job.result.source_refs匹配source:source_id；提交后的pending/failed关联只通过当前会话提交记录，不把项目所有jobs当该来源历史。取消事件cancel_requested，Job仍running；重试显式replay新run_id。失败不能抹掉原来源快照/已有成功结果。无实际parse成功不给“可用于建模”。

无业务模拟/样例记录。独立测试允许最小领域无关夹具，不进入产品factory。部署/端口与DSH GUI分离，不启动替代DSH服务。
