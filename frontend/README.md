# 前端工作台

React/TypeScript 前端包含两个已合并模块：数据接入和本体构建。二者共享本地工作台身份、项目选择、来源快照、任务运行与 workspace revision。页面不显示登录表单，后端需使用 `--single-user` 启动本地原型。

## 页面能力

数据接入支持真实文件上传、解析、结构与样本质量查看、来源版本证据和进入本体构建。

本体构建采用五阶段单页切换：

1. 场景理解：真实来源、语义任务和修订概览
2. 业务问题：展示后端能力缺口，等待结构化持久化接口
3. 模型方案：读取五类修订并保存 JSON 草稿
4. 场景验证：展示真实 `validate_shacl` 任务及结果
5. 交付中心：汇总修订就绪度，发布能力未开放时保持操作禁用

页面不会把连接配置表达为数据已接入，也不会生成虚构的任务历史、访谈结论或业务金标。

## 开发与验证

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm dev
```

Vite 使用同源 `/api` 契约。后端启动、账号、连接和语义任务配置见 `docs/operations`。生产构建不依赖 CDN 字体或外部脚本。
